# Стайлгайд документации Booking API

Руководство по стилю для внешней технической документации REST API сервиса бронирования переговорных комнат, версия 1.0.0.

## Аудитория

Разработчики интеграций, знакомые с HTTP и JSON.

## Что входит

- обзор API;
- быстрый старт;
- справочник операций;
- описание ошибок;
- журнал изменений.

## Что не входит

Архитектура сервиса, исходный код, внутренние инструкции администраторов.
