# Структура документов

- **D01 (обязательно).** Для каждой операции описать условия, запрос, ответ, ограничения и ошибки.
- **D02 (обязательно).** Один шаг — одно действие. В конце — ожидаемый результат.
- **D03 (обязательно).** Шаги нумеровать, независимые условия — маркированным списком.
- **D04 (обязательно).** В быстром старте — минимальный рабочий пример.
