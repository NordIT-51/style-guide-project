# Формат и Markdown

- **F01 (обязательно).** У блока кода указывать язык: `bash`, `json`, `http`.
- **F02 (обязательно).** У таблиц — заголовки столбцов, у изображений — alt-текст.
- **F03 (обязательно).** Заголовки не пропускать по уровням, один H1 на страницу.
- **F04 (рекомендуется).** Длинные строки в примерах переносить по правилам языка.
