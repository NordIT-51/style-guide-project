# Качество

- **Q01 (обязательно).** Перед merge — линтер, проверка JSON, `mkdocs build --strict`.
- **Q02 (обязательно).** Примеры должны запускаться или проверяться скриптом.
- **Q03 (обязательно).** Изменения проходят через ветку и Pull Request.
- **Q04 (рекомендуется).** Версия правил фиксируется в `mkdocs.yml`.
