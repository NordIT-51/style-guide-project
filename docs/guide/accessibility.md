# Доступность текста

Правила основаны на WCAG 2.2 уровня AA. Они помогают сделать документацию удобной для людей с разными возможностями.

- **X01.** Писать простыми предложениями, избегать сложных конструкций.
- **X02.** Один H1 на страницу, заголовки не пропускать по уровням.
- **X03.** Ссылки и кнопки называть по действию, а не по цвету или положению.
- **X04.** У изображений — содержательный alt-текст, передающий смысл (например, «форма с полями логин и пароль», а не просто «скриншот формы»).
- **X05.** Не полагаться только на цвет для передачи информации.
- **X06.** Таблицы — с заголовками столбцов, код — текстом, не картинкой.
- **X07.** Проверять страницу при ширине 320 CSS-пикселей.
- **X08.** Проверять страницу при масштабировании до 200 %.
- **X09.** Проверять навигацию с клавиатуры: порядок перехода логичный, ссылки и кнопки срабатывают по Enter.
