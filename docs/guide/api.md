# REST API

- **A01 (обязательно).** Различать отсутствие поля и значение `null`.
- **A02 (обязательно).** Указывать обязательность полей и ограничения (диапазон, длина, формат).
- **A03 (обязательно).** Коды ошибок сверять с RFC 9457: `type`, `title`, `status`, `detail`, `instance`.
- **A04 (обязательно).** Для каждой операции указывать метод, путь, авторизацию, параметры, коды ответов.
- **A05 (обязательно).** В примерах использовать тестовые токены и явную пометку `test`.
